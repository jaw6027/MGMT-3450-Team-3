# Shared class project instructions

Multiple students develop this application in separate Codex chats connected to
the same GitHub repository. Follow these instructions for every task:

1. Before making changes, retrieve the latest version of the repository. Inspect
   the working tree, fetch the shared branch, and safely incorporate its latest
   changes while preserving any existing local work.
2. Preserve all existing application functionality.
3. Do not overwrite or discard another student's work, including uncommitted
   changes and files outside the scope of your task.
4. After completing a task, test the changes and commit them with a descriptive
   commit message. Stage only the files belonging to your task.
5. Push completed changes to the shared GitHub repository.
6. Immediately before pushing, fetch the shared branch again and check whether
   other students have pushed new changes. If so, incorporate those changes
   safely and rerun relevant tests before pushing. If a push is rejected because
   the shared branch advanced, repeat this process.
7. If conflicting changes cannot be safely combined, stop and explain the
   conflict rather than overwriting anyone's work.
8. Never force-push to the shared repository.
